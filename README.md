# Система управления данными с аутентификацией

Веб-приложение для управления данными доставок с аутентификацией пользователей.

## Установка и запуск

### 1. Настройка базы данных Supabase

1. Откройте https://app.supabase.com и выберите ваш проект
2. Перейдите в **SQL Editor**
3. Выполните SQL-запросы из файла `init_db.py` (запустите `python init_db.py` для отображения запросов)

### 2. Переменные окружения

Убедитесь, что следующие переменные настроены в Replit Secrets:
- `SUPABASE_URL` - URL вашего проекта Supabase
- `SUPABASE_KEY` - API ключ Supabase (anon/public key)
- `SESSION_SECRET` - секретный ключ для сессий

### 3. Запуск приложения

```bash
python main.py
```

Приложение будет доступно по адресу: `http://localhost:5000`

## Функциональность

### Аутентификация
- Регистрация новых пользователей
- Вход в систему
- Безопасное хеширование паролей (bcrypt)
- Управление сессиями

### Управление доставками
- Просмотр всех доставок в интерактивной таблице
- Добавление новых записей
- Редактирование существующих записей
- Удаление записей

## Технологии
- Flask - веб-фреймворк
- Supabase - база данных PostgreSQL
- Bootstrap 5 - UI фреймворк
- bcrypt - хеширование паролей
- Flask-Login - управление сессиями
