# Система управления данными с аутентификацией

Веб-приложение для управления данными доставок с аутентификацией пользователей.

## 🚀 Быстрый старт

База данных уже инициализирована! Приложение готово к использованию.

1. **Зарегистрируйтесь** - создайте новый аккаунт
2. **Войдите** - используйте свои учетные данные
3. **Управляйте доставками** - добавляйте, редактируйте и удаляйте записи

## 📋 Переменные окружения

Следующие переменные уже настроены в Replit Secrets:
- ✅ `SUPABASE_URL` - URL проекта Supabase
- ✅ `SUPABASE_KEY` - API ключ Supabase
- ✅ `SESSION_SECRET` - секретный ключ для сессий

## 🔧 Переинициализация базы данных

Если нужно пересоздать таблицы, выполните:

```bash
python setup_database.py
```

Или выполните SQL-запросы вручную (смотрите `python init_db.py`)

## Функциональность

### Аутентификация
- Регистрация новых пользователей
- Вход в систему
- Безопасное хеширование паролей (bcrypt)
- Управление сессиями

### Управление доставками
- Просмотр всех доставок в интерактивной таблице
- Добавление новых записей
- Редактирование существующих записей
- Удаление записей

## Технологии
- Flask - веб-фреймворк
- Supabase - база данных PostgreSQL
- Bootstrap 5 - UI фреймворк
- bcrypt - хеширование паролей
- Flask-Login - управление сессиями
